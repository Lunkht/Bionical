Une CLI qui se branche partout

Lit l’entrée standard, écrit sur la sortie standard.

git diff | bionical run -p "Résume ces changements" cat notes.md | bionical run -p "Corrige l’orthographe" > propre.md

De zéro à votre premier prompt en trois commandes

1

Installer

Un binaire, aucun service à configurer.

curl -fsSL https://bionical.com/install | sh
2

Télécharger un modèle

Vérifié par somme de contrôle.

bionical pull qwen2.5-coder:7b
3

Lancer

Dans le terminal ou l’application.

bionical run qwen2.5-coder:7b

Questions fréquentes

Faut-il une connexion Internet ?

Seulement pour télécharger Bionical et les modèles. Ensuite, tout fonctionne hors ligne.

Mes données sont-elles envoyées quelque part ?

Non. Les requêtes sont traitées sur votre appareil. Les statistiques d’usage sont désactivées par défaut.

Quel matériel faut-il ?

4 Go de mémoire suffisent pour les petits modèles, 8 Go sont conseillés pour les modèles de 7 milliards de paramètres.

Puis-je utiliser mes propres modèles ?

Oui. Importez n’importe quel fichier GGUF avec bionical import.

Une IA utile ne devrait pas exiger vos données

Bionical est né d’un constat : la plupart des assistants envoient vos fichiers à un serveur distant pour répondre à une question. Les modèles ouverts sont désormais assez petits pour tourner sur un portable ou un téléphone.

Nous construisons les outils pour les exécuter simplement : une application, une CLI et un format ouvert. Pas de dépendance à un service tiers pour répondre, pas de compte obligatoire pour s’en servir hors ligne.
